# MomentTune ArtBox Roadmap

## Phase 1: Repositioning

- Rename product language from gallery to content platform.
- Establish mission and documentation.
- Define content schema.
- Define engineering harness.
- Align existing artworks with emotional intent.

## Phase 2: Content Engine Foundation

- Build metadata-driven content registry.
- Add content categories and emotion tags.
- Create shared ContentShell and ContentViewer.
- Add dynamic loading per content item.
- Add preview component contract.

## Phase 3: MVP Emotional Loop

- Add mood input.
- Recommend content from metadata.
- Launch Calm, Focus, and Breathing sessions.
- Add session feedback.
- Track completion and before/after mood.

## Phase 4: Recommendation Integration

- Connect HR, HRV, Sleep, Stress, Mood, Weather, and Time inputs.
- Implement recommendation scoring.
- Add context and preference weighting.
- Feed analytics back into content ranking.

## Phase 5: Personalization

- Add AI-adjusted runtime parameters.
- Personalize duration, intensity, color, sound, and interaction mode.
- Build user preference profiles.
- Add adaptive content variants.

## Phase 6: Platform Expansion

- Create creator-ready content templates.
- Add validation tools for metadata and accessibility.
- Launch emotional wellness programs.
- Support enterprise and education use cases.

## Near-Term Priorities

1. Move from artwork data to content schema.
2. Fix route and data inconsistencies.
3. Create reusable content viewer.
4. Add recommendation metadata to existing content.
5. Add mobile and accessibility checks.

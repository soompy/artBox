# MomentTune ArtBox Experience Principles

> 2026-11-02 고쳐 씀 — 정본은 [`MOTI_CAFE_BRIEF.md`](MOTI_CAFE_BRIEF.md). 그 전의 «감정 변화를 위해 존재한다» · 세션 전후 감정 확인(before/after) · «source → target emotion» 기준은 [`PARKED.md`](PARKED.md) P-1 · P-2 로 뗐다.

모든 ArtBox 작품은 **모티가 한 공간을 즐기는 장면 곁에 방문자가 잠깐 앉아 있는 경험**입니다.

## Calm

조용함은 ArtBox 의 기본값입니다. 장면은 방문자를 압도하지 않고, 언제든 멈추고 나갈 수 있어야 합니다.

UX 구현:

- 부드럽고 예측 가능한 움직임을 사용합니다.
- 빠른 깜빡임 · 번쩍임 · 화면 진동 · 큰 소리를 쓰지 않습니다.
- 소리 끄기와 나가기를 항상 접근 가능하게 둡니다. 화면을 숨기면 멈추고 돌아오면 이어집니다.

## Delight

작은 손짓에 장면이 반응하는 순간에서 나옵니다.

UX 구현:

- 두드리면 무언가 움직입니다(빗방울이 흐르고 · 김이 피어오르고 · 모티가 이쪽을 봅니다).
- 같은 곳을 여러 번 두드려도 새로 열리는 것이 없습니다. 횟수를 세지 않습니다.
- 성과가 아니라 곁에 있음을 그대로 둡니다 — 점수 · 보상 · 연속 기록 ✗.

## Curiosity

방문자가 혼란 없이 둘러보고 싶어지는 감각입니다.

UX 구현:

- 시작 안내는 한 줄만(«두드리면 무언가 움직여요 · 빗소리는 오른쪽 위에서»).
- 장면의 작은 사건(지나가는 우산 · 넘기는 책장)은 시간에 따라 천천히 드러납니다.
- 모든 두드림이 반응을 만듭니다.

## 곁에 있기

방문자는 모티를 돌보거나 상담하지 않습니다. 쉬는 날을 즐기는 모티 곁에 같이 앉아 있을 뿐입니다.

UX 구현:

- 시작 전에 기분을 묻지 않습니다. 끝난 뒤에도 묻지 않습니다.
- 장면이 흐르는 동안 UI 를 줄입니다.
- 말풍선 대화 · 사용자 글 · «지금 N명이 같이 앉아 있어요» 를 두지 않습니다.

## Simplicity

링크를 연 사람의 진입 부담을 낮춥니다.

UX 구현:

- 링크 → 장면 → 끝 화면, 세 단계뿐입니다. 로그인 · 설치 · 선택 화면이 없습니다.
- 끝 화면의 행동은 세 가지(쉴 곳 지도 보기 · 한 번 더 앉아 있기 · 친구에게)로 제한합니다.

## Accessibility

UX 구현:

- 소리 없이도 성립합니다(빗소리는 기본 꺼짐).
- reduced motion 을 지원합니다(비 · 빗방울 정지, 모티는 가끔 깜빡임만, 끝 화면은 바로).
- WebGL fallback 을 제공합니다.
- 키보드로 «두드리기» 를 할 수 있고, 끝 화면이 뜨면 포커스를 옮깁니다.
- 장면을 화면 읽기용 한 문장으로 설명합니다.
- 색상만으로 의미를 전달하지 않습니다.

## Beauty

UX 구현:

- MomentTune 모티 자산과 같은 결 — 색연필 · 크레용 질감, 따뜻한 종이톤.
- 장면이 흐르는 동안 UI 는 조용해야 합니다.
- 빈 공간과 느린 변화를 의도적으로 사용합니다.

## 한 일만 말하기

화면에 나오는 글자는 방문자가 **한 일**만 말합니다.

UX 구현:

- 끝 화면 문구는 «잠깐 같이 앉아 있었네요». «마음이 편해졌죠?» 같은 효과 질문 ✗.
- 제목 · 설명 · OG · 공유 문구도 같은 기준(브리프 §2-1 표).
- 조회수나 기분 변화를 재지 않습니다. 재는 것은 브리프 §6(서버 요청 수 · App Store 캠페인)뿐입니다.

## 내보내기 전 확인

- 모티가 어떤 공간에서 무엇을 하는 장면인지 한 문장으로 말할 수 있는가?
- 첫 5초 안에 «두드리면 된다» 가 보이는가?
- 화면 · 메타 · OG 에 효과를 약속하는 말이 없는가?
- 점수 · 횟수 · 보상이 없는가?
- 기분을 묻거나 기록하지 않는가? 쿠키 · localStorage · 분석 스크립트가 없는가?
- 소리 없이도 성립하는가?
- 언제든 나갈 수 있는가?
- reduced motion 을 지원하는가? 빠른 깜빡임 · 화면 진동이 없는가?
- 휴대폰 세로 화면에서 작동하는가?

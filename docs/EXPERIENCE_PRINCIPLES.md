# MomentTune ArtBox Experience Principles

모든 ArtBox 작품은 모티 곁에 잠깐 같이 앉아 있는 경험을 위해 존재합니다. 효과를 약속하지 않고, 한 일만 말합니다.

## Calm

Calm 은 ArtBox 의 기본 정서입니다. 장면은 사용자를 압도하지 않고 통제감을 줘야 합니다.

UX 구현:

- 부드럽고 예측 가능한 모션을 사용합니다.
- 빠른 깜빡임, 번쩍임, 화면 진동, 큰 소리, 공격적인 애니메이션을 쓰지 않습니다.
- 소리 버튼과 나가기는 항상 보이게 둡니다. 화면을 숨기면 멈추고 돌아오면 이어집니다.

## Delight

Delight 는 장면이 사용자의 손짓에 작게, 아름답게 반응한다고 느끼는 순간에서 나옵니다.

UX 구현:

- 두드림 하나에도 살아 있는 반응을 줍니다(빗방울이 흘러내림 · 김이 피어오름 · 모티가 이쪽을 봄).
- 성과가 아니라 함께 있음을 보여 줍니다. 점수 · 횟수 · 보상 · 새로 열리는 것이 없습니다.

## Curiosity

Curiosity 는 사용자가 혼란 없이 둘러보고 싶어지는 감각입니다.

UX 구현:

- 첫 3초에 제목과 한 줄 안내(«두드리면 무언가 움직여요»)만 보여 주고 사라집니다.
- 장면의 작은 변화(우산이 지나감 · 책장을 넘김)는 2분에 걸쳐 천천히 드러납니다.
- 어디를 두드려도 유효한 반응이 있습니다.

## Presence

Presence 는 사용자가 모티 곁에 같이 앉아 있다고 느끼는 감각입니다.

UX 구현:

- 시작 전에 아무것도 묻지 않습니다(감정 체크인 · 입력 없음).
- 장면이 진행되는 동안 UI 를 줄입니다(얇은 진행선 · 소리 버튼 · 나가기).
- 끝 화면은 한 일만 말합니다 — «잠깐 같이 앉아 있었네요». 기분이 어땠는지 묻지 않습니다.

## Simplicity

Simplicity 는 처음 온 사람의 진입 부담을 낮춥니다.

UX 구현:

- 링크 → 장면 → 끝 화면, 이 길만 있습니다.
- 끝 화면의 선택지는 셋입니다: 쉴 곳 지도에서 보기 · 한 번 더 앉아 있기 · 친구에게.
- 설정 화면이 없습니다.

## Accessibility

Accessibility 는 안전의 일부입니다.

UX 구현:

- 소리 없이 성립합니다(소리는 기본 꺼짐, 누른 사람만 듣습니다).
- 움직임 줄이기(`prefers-reduced-motion`)를 지원합니다.
- WebGL fallback 을 제공합니다.
- 키보드로 두드리기 · 나가기가 가능합니다.
- 화면 읽기에 장면을 한 문장으로 알려 줍니다.
- 색상만으로 의미를 전달하지 않습니다.

## Beauty

Beauty 는 장면의 핵심입니다.

UX 구현:

- 그림 결은 MomentTune 모티 자산과 같게 — 색연필·크레용 질감 · 따뜻한 종이톤.
- 장면 중 UI 는 조용해야 합니다.
- 빈 공간과 느린 변화를 의도적으로 사용합니다.

## Release Checklist

- 이 작품은 어떤 공간에서 모티가 무엇을 즐기는 장면인가?
- 사용자는 어떤 손짓을 할 수 있는가?
- 끝 화면은 «쉴 곳 지도» 의 어떤 장소 종류로 이어지는가?
- 첫 3초 안에 무엇을 보고 있는지 알 수 있는가?
- 소리 없이도 성립하는가?
- 나가기가 언제든 가능한가?
- 움직임 줄이기를 지원하는가?
- 모바일(세로 화면)에서 작동하는가?
- 효능·감정 전환 문구, 점수·횟수·보상, 분석 스크립트·쿠키가 없는가?

이전 원칙의 감정 체크인 · before/after 감정 확인 · mood change 측정은 [`parked/README.md`](parked/README.md) 에 보류했습니다.

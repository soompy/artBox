# MomentTune ArtBox Experience Principles

모든 ArtBox 콘텐츠는 사용자의 감정 변화를 위해 존재합니다.

## Calm

Calm은 ArtBox의 기본 정서입니다. 경험은 사용자를 압도하지 않고 통제감과 안전감을 제공해야 합니다.

UX 구현:

- 부드럽고 예측 가능한 모션을 사용합니다.
- 갑작스러운 플래시, 큰 소리, 공격적인 애니메이션을 피합니다.
- Pause, Sound Off, Exit를 항상 접근 가능하게 둡니다.

## Delight

Delight는 콘텐츠가 사용자의 행동에 아름답게 반응한다고 느끼는 순간에서 나옵니다.

UX 구현:

- 작은 상호작용도 살아 있는 피드백을 제공합니다.
- 시각과 사운드 반응을 섬세하게 설계합니다.
- 성과가 아니라 존재감을 보상합니다.

## Curiosity

Curiosity는 사용자가 혼란 없이 탐색하고 싶어지는 감각입니다.

UX 구현:

- 시작 행동은 하나만 명확하게 제시합니다.
- 콘텐츠의 깊이는 점진적으로 드러냅니다.
- 모든 상호작용이 유효한 반응을 만들도록 합니다.

## Mindfulness

Mindfulness는 사용자가 현재 순간의 감각과 감정을 알아차리도록 돕습니다.

UX 구현:

- 짧은 감정 체크인으로 시작합니다.
- 콘텐츠가 진행되는 동안 UI를 줄입니다.
- 세션 종료 후 before/after 감정을 확인합니다.

## Simplicity

Simplicity는 감정적으로 지친 사용자의 진입 부담을 낮춥니다.

UX 구현:

- emotion -> recommendation -> start 경로를 짧게 유지합니다.
- 선택지는 제한합니다.
- 고급 설정은 필요할 때만 노출합니다.

## Accessibility

Accessibility는 감정적 안전의 일부입니다.

UX 구현:

- sound-off 경험을 지원합니다.
- reduced motion을 지원합니다.
- WebGL fallback을 제공합니다.
- keyboard-accessible controls를 제공합니다.
- 색상만으로 의미를 전달하지 않습니다.

## Beauty

Beauty는 감정 조율의 기능적 요소입니다.

UX 구현:

- 색, 사운드, 모션, 타이포그래피가 감정 목표와 일치해야 합니다.
- 몰입 중 UI는 조용해야 합니다.
- 빈 공간과 느린 변화를 의도적으로 사용합니다.

## Emotion First

Emotion은 가장 중요한 제품 요구사항입니다.

UX 구현:

- 구현 전에 source emotion과 target emotion을 정의합니다.
- 감정 전환에 기여하지 않는 효과는 거절합니다.
- 조회수보다 mood change를 측정합니다.

## Release Checklist

- 이 콘텐츠는 어떤 감정 상태를 위한 것인가?
- 사용자는 어떤 상태로 이동해야 하는가?
- 첫 5초 안에 행동이 명확한가?
- 사운드 없이도 성립하는가?
- pause와 exit가 가능한가?
- reduced motion을 지원하는가?
- 모바일에서 작동하는가?

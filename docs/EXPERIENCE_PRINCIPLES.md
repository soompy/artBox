# MomentTune ArtBox Experience Principles

All ArtBox content must serve emotional change.

## Calm

Calm is the default emotional posture. Experiences should reduce overwhelm and give users control.

UX implementation:

- Use soft transitions and predictable motion.
- Avoid sudden flashes, loud starts, or aggressive animation.
- Keep Pause, Sound Off, and Exit available.

## Delight

Delight comes from feeling that the content responds beautifully to the user.

UX implementation:

- Make small interactions feel alive.
- Use subtle visual and audio feedback.
- Reward presence, not performance.

## Curiosity

Curiosity invites exploration without confusion.

UX implementation:

- Start with one clear action.
- Reveal depth gradually.
- Make every interaction valid.

## Mindfulness

Mindfulness helps the user notice the present moment.

UX implementation:

- Ask for a short emotional check-in.
- Reduce UI while the content is active.
- End with a simple before/after reflection.

## Simplicity

Simplicity lowers emotional friction.

UX implementation:

- Use a short path: emotion -> recommendation -> start.
- Keep choices limited.
- Hide advanced settings until needed.

## Accessibility

Accessibility is part of emotional safety.

UX implementation:

- Support sound-off usage.
- Support reduced motion.
- Provide WebGL fallback.
- Use keyboard-accessible controls.
- Avoid color-only meaning.

## Beauty

Beauty is a functional part of emotional regulation.

UX implementation:

- Align color, sound, motion, and typography with the emotional goal.
- Keep UI quiet during immersion.
- Use empty space and slow change intentionally.

## Emotion First

Emotion is the primary product requirement.

UX implementation:

- Define source emotion and target emotion before implementation.
- Reject effects that do not support the intended emotional shift.
- Measure mood change, not just engagement.

## Release Checklist

- What emotional state is this for?
- What state should the user move toward?
- Is the first action clear within five seconds?
- Does it work without sound?
- Can the user pause and exit?
- Does it support reduced motion?
- Does it work on mobile?

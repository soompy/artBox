# MomentTune ArtBox Service Definition

## Service Definition

ArtBox is an interactive emotional wellness content service.

It recommends and renders short interactive sessions that help users shift their emotional state. The core output is not an artwork view. The core output is an emotional transition.

## Problem

Users feel anxious, tired, scattered, lonely, or overstimulated, but most digital products either demand more attention or require high-effort wellness routines.

Existing options often feel too passive, too clinical, too long, or too generic.

## Solution

ArtBox provides metadata-driven interactive content matched to the user's emotional state and context.

The service flow:

1. Understand the user's state.
2. Recommend an emotional content session.
3. Render a short interactive experience.
4. Collect feedback.
5. Improve future recommendations.

## Target User

Primary users:

- MomentTune users who want emotional support through content.
- People who need short wellness moments during the day.
- Users who prefer sensory, visual, or interactive experiences over long text or meditation.

Secondary users:

- Creative professionals seeking emotional reset.
- Students and workers needing focus or decompression.
- Users interested in digital wellness and interactive media.

## User Value

- Fast emotional reset.
- Low cognitive effort.
- Beautiful sensory interaction.
- Personal relevance through recommendation.
- Gentle feedback loop.

## User Story

As a user feeling anxious before sleep, I open MomentTune ArtBox, choose or confirm my mood, receive a Calm or Breathing session, interact with soft visuals for two minutes, and leave feeling more settled.

- Emotion input

- Recommendation-ready content list
- Interactive content viewer
- Mobile support
- Sound optional mode
- Session feedback

### P1

- Recommendation scoring

### P2

- Adaptive content parameters

## MVP

The MVP must prove the core loop:

Emotion input -> recommended content -> interactive session -> feedback.

MVP categories:

- Calm
- Focus
- Breathing

MVP metrics:

- Start rate
- Completion rate
- Mood improvement rate
- Mobile completion rate
- Repeat usage

## Future Expansion

- HR, HRV, sleep, stress, weather, and time-based recommendations.
- AI-adjusted motion, sound, palette, and duration.
- Creator ecosystem for emotional interactive content.
- B2B wellness and education programs.

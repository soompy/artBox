# MomentTune ArtBox Service Definition

## Service Definition

ArtBox 는 MomentTune 앱으로 들어오는 **설치 없는 웹 입구**입니다. 링크를 누르면 수달 캐릭터 «모티» 가 한 공간을 즐기는 2분짜리 장면이 열리고, 끝 화면에서 «이번 주말, 이런 곳 하나» 로 MomentTune «쉴 곳 지도» 에 이어집니다.

핵심 산출물은 **링크 하나로 끝까지 보는 장면**과, 그 끝에서 앱으로 넘어가는 한 번의 클릭입니다.

## Problem

MomentTune 앱은 공개 한 달 동안 사람을 거의 모으지 못했습니다(메타 광고 클릭 696 → 설치 1). 들어오는 길(광고 → 홈페이지 → App Store → 설치 → 온보딩)이 길었고, **한 문장 · 한 장면 · 한 번의 클릭**이 없었습니다.

MomentTune 이 겨냥하는 결핍은 **«쉬는 날 뭘 하지»** 입니다.

## Solution

- 설치 · 가입 · 입력 없이 열리는 웹 장면
- 장면의 공간 = «쉴 곳 지도» 의 장소 종류(카페 · 전시 · 산책 · 서점 · 공원 · 마켓)
- 끝 화면의 버튼 하나가 App Store 캠페인 링크로 이어짐

서비스 흐름:

1. 사용자가 SNS·친구에게서 받은 링크를 엽니다.
2. 모티가 공간을 즐기는 장면을 2분 같이 봅니다. 원하면 장면을 두드려 작은 반응을 봅니다.
3. 끝 화면에서 «쉴 곳 지도에서 카페 보기» 로 MomentTune 에 넘어가거나, 한 번 더 앉아 있거나, 친구에게 보냅니다.

## Target User

Primary user:

- 쉬는 날 뭘 할지 정하지 못한 사람
- SNS 에서 링크를 보고 설치 없이 잠깐 들어와 보는 사람

Secondary user:

- 이미 MomentTune 을 쓰는 사용자(앱에서 열면 «모먼트튠으로 돌아가기»)
- 링크를 받아 친구에게 다시 보내는 사람

## JTBD

쉬는 날 뭘 할지 떠오르지 않을 때, 나는 부담 없이 잠깐 들여다볼 수 있는 장면에서 «이런 곳 하나 가 볼까» 하는 생각을 얻고 싶다.

## User Value

- 설치 없이 바로 열림
- 해야 할 일이 없는 2분
- 모티라는 우리만의 장면
- 끝에서 이번 주말 갈 만한 장소 하나

## User Story

비 오는 주말 아침, 사용자가 스레드에서 «모티의 쉬는 날 · 창가 자리» 링크를 누릅니다. 카페 창가에서 코코아를 마시는 모티 곁에 2분 같이 앉아 있다가, 유리창을 두드려 빗방울이 흘러내리는 걸 봅니다. 끝 화면의 «잠깐 같이 앉아 있었네요» 아래 «쉴 곳 지도에서 카페 보기» 를 눌러 App Store 로 넘어갑니다.

## Feature Priority

### P0

- 장면 하나(레이어 · 120초 흐름 · 진행선 · 언제든 나가기)
- 두드림 반응 네 곳
- 끝 화면(App Store 캠페인 링크 · 한 번 더 · 친구에게)
- 모바일(세로 화면) 먼저
- 소리 기본 꺼짐 · 움직임 줄이기 · 키보드 · 화면 읽기
- 한국어 메타 · OG 이미지

### P1

- 다음 공간 작품(`/moti/<공간>`, 예: `/moti/bookstore`)
- 앱에서 열었을 때(`?from=momenttune`) «모먼트튠으로 돌아가기»

### P2

- 보류: «함께 있음»(숫자 없이 실루엣만 — 지금은 넣지 않음)

## MVP

첫 작품 **카페 «모티의 쉬는 날 · 창가 자리»** 하나로 입구를 시험합니다. 세부는 [`MOTI_CAFE_BRIEF.md`](MOTI_CAFE_BRIEF.md).

MVP 에서 재는 것 — 숫자 기준 없이 «재기만»(브리프 §6):

- 방문: `?from=` 별 서버 요청 수
- 끝까지: 끝 화면 자원 요청 수(서버 로그 합계)
- 넘어감: App Store Connect 캠페인 `ct=artbox_cafe` 의 페이지 조회·다운로드
- 감상: 창업자 주변 몇 명에게 «또 열어 볼 것 같나» 를 직접 묻기

쿠키·분석 스크립트로 재지 않습니다. 기분 전후 비교 · 심박·HRV 는 재지 않습니다.

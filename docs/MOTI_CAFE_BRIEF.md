> **artBox 에서 이 작품을 만드는 사람(또는 AI)이 가장 먼저 읽는 문서다.** 이 한 장으로 시작할 수 있게 썼다.
> 기획의 정본은 MomentTune 앱 레포에 있다 — 이 문서는 그 결정을 artBox 작업용으로 옮긴 것이다(§10 링크).
> 이 문서와 `MISSION.md`·`docs/*` 가 다르면 **이 문서가 이긴다**(§2 — 기존 문서 일부는 정리 대상이다).

| **artBox 의 자리** | MomentTune 앱(집)으로 들어오는 **설치 없는 웹 입구** — 독립 제품이 아니다 |

## 1. 왜 이걸 만드나 (배경 요약)

- MomentTune 앱은 공개 한 달 동안 사람을 거의 모으지 못했다 — 메타 광고 클릭 696 → 설치 1. 들어오는 길(광고 → 홈페이지 → App Store → 설치 → 온보딩)이 길었고, **한 문장 · 한 장면 · 한 번의 클릭**이 없었다
- 2026-10 말 화제가 된 웹 가상 사찰 «산사»(개발자 집계 사흘 60만 방문)는 그 셋을 다 가졌다 — 설치 없는 링크, 동자승이 줄지어 절하는 장면, 말 없는 함께 있음
- 그래서 **«앱은 집, 설치 없는 웹 입구는 따로»**. 입구는 산사를 따라 하지 않고 **우리 캐릭터 모티**로 만든다
- 모티가 즐기는 **공간 = MomentTune «쉴 곳 지도» 의 장소 종류**(카페 · 전시 · 산책 · 서점 · 공원 · 마켓). 끝 화면이 «이번 주말, 이런 곳 하나» 로 앱에 이어진다 — MomentTune 이 겨냥하는 결핍은 **«쉬는 날 뭘 하지»**
- 첫 작품이 **카페**인 이유: 창업자가 «쉬는 날 하고 싶은 것» 으로 든 예 중 하나(새 카페 찾기) · 쉴 곳 지도에 카페가 가장 많다 · «비 오는 날 창가 자리» 는 설명이 필요 없는 장면
- 기존 작품 «점심의 틈» 은 입구로 쓰지 않는다(창업자 판단 — 수요 없음). «출근의 리듬» 도 입구에서 뺀다(§2-5)

## 2. 반드시 지킬 것 — MomentTune 원칙 (이 작품은 MomentTune 이름을 단다)

1. **비의료** — 진단·치료·효능을 말하지 않는다. 화면·제목·설명·OG·SNS 어디에도:

   | 쓰는 말 | 쓰지 않는 말 |
   |---|---|
   | 모티의 쉬는 날 · 모티랑 2분 · 창가 자리 · 잠깐 같이 앉아 있기 | 힐링 · 치유 · 마음이 편해져요 · 불안·긴장이 풀려요 · 감정 전환 · 안정시킨다 · 평온함을 선사 · 명상 |

   - 기획 안에서 «휴식과 힐링이 필요한 모티» 라고 부르는 건 괜찮다. **밖으로 나가는 글자에는 «힐링» 을 쓰지 않는다**
2. **게이미피케이션 없음** — 점수 · 횟수 · 연속 · 보상 · 성장 · 먹이 · 모으기 도감 · «다 찾았어요» ✗. 키우기 게임이 아니다
3. **모티는 쉬는 날을 즐기는 모습** — 지쳐 쓰러진 모티를 사용자가 돌보는 구도 ✗(감정 돌봄·상담처럼 읽힌다). 힘든 표정 금지
4. **개인정보** — 분석 스크립트 · 쿠키 · localStorage 기록 ✗ · 링크에 상태·건강 값 ✗ · **기분 전후 비교 · 심박·HRV 연동 ✗** · 외부 폰트 호출 ✗(방문자 IP 가 넘어간다)
5. **안전** — 빠른 깜빡임·번쩍임·화면 진동 ✗. «출근의 리듬» 의 번개·화면 진동 장면은 광과민·전정 위험이 있어 입구에 쓰지 않는다
6. **호스팅** — Vercel 이 아니라 **`momenttune.com/moti/…`**(MomentTune 홈페이지와 같은 Cloudflare). 카페 작품 주소는 **`momenttune.com/moti/cafe`**(창업자 2026-11-02). Vercel 에 두면 MomentTune 처리방침에 수탁자를 새로 적어야 한다

## 3. 작품

### 3-1. 장면

```
┌─────────────────────────────┐
│  ╭─ 창 ───────────────╮   🔈 │  ← 오른쪽 위: 빗소리 버튼(기본 꺼짐)
│  │ / / 비 / /  흐린 거리 │      │  ← 창밖: 비, 우산이 가끔 지나감
│  │  / /   / /   / /   │      │     유리에 빗방울이 맺혔다 흘러내림
│  ╰────────────────────╯      │
│        ~ ~ 김                │
│     ( 모티 )  [머그잔]         │  ← 창가 바 자리, 두 손으로 머그를 감싼 모티
│   ──────── 나무 선반 ─────     │     옆에 작은 화분 · 펼친 책 한 권
│                              │
│ 모티의 쉬는 날 · 창가 자리       │  ← 첫 3초만 보이고 사라지는 제목
└─────────────────────────────┘
```

- **세로 화면(휴대폰) 먼저** — 가로·데스크톱은 같은 장면을 가운데에
- 그림 결: MomentTune 모티 자산과 같게 — **색연필·크레용 질감 · 따뜻한 종이톤**(어두운 갤러리 톤 ✗)

### 3-2. 2분 흐름

| 시간 | 모티 | 화면 |
|---|---|---|
| 0~3초 | 창밖을 보며 앉아 있다 | 제목 «모티의 쉬는 날 · 창가 자리» 가 떴다 사라짐 · 작은 글씨 «두드리면 무언가 움직여요 · 빗소리는 오른쪽 위에서» |
| 3초~ | 가끔 머그를 들어 한 모금 · 천천히 깜빡 · 꼬리가 살짝 흔들림 | 비가 계속, 빗방울이 유리를 타고 흐른다 |
| 약 60초 | 책장을 한 장 넘긴다 | 창밖에 노란 우산 하나가 지나간다 |
| 약 100초 | 하품 · 꾸벅 | 빗발이 가늘어진다 |
| 120초 | 머그를 내려놓고 꾸벅 존다 | 빗소리가 잦아들고 끝 화면이 천천히 올라온다 |

- 시간 틀은 «점심의 틈»(`src/components/artworks/LunchBreak.tsx`)과 같게 — `SESSION_SECONDS = 120` · 얇은 진행선 · 언제든 나가기 · 화면을 숨기면 멈추고 돌아오면 이어짐 · 저전력

### 3-3. 손짓 하나 — 두드리면

| 두드린 곳 | 반응 |
|---|---|
| 유리창 | 빗방울 하나가 또르르 흘러내린다 |
| 머그잔 | 김이 한 번 더 피어오른다 |
| 모티 | 고개를 돌려 이쪽을 한 번 보고 눈을 감았다 뜬다 — **말풍선 없음** |
| 창밖 | 우산 하나가 천천히 지나간다 |

같은 곳을 여러 번 두드려도 **새로 열리는 것이 없다**. 횟수 표시 없음.

### 3-4. 빗소리 — 켜고 끌 수 있게

- **기본 꺼짐.** 화면 구석에 늘 보이는 버튼 하나(🔈 꺼짐 / 🔊 빗소리) — 누른 사람만 듣는다
- 브라우저는 사용자가 누르기 전 소리를 막는다 → **버튼을 누르는 순간 재생**(자동 재생 ✗)
- 말 없는 빗소리 한 가지 · 끊김 없이 반복 · 끝 화면이 올라오면 천천히 줄어든다
- 켬/끔은 **그 화면 안에서만** 기억한다(쿠키·localStorage ✗)
- 버튼 이름 «빗소리 켜기 / 끄기» · 지금 상태를 읽어 준다 · 누르기 넉넉한 크기(44pt 이상)
- **소리 파일은 아직 없다** — MomentTune 앱에도 빗소리가 없다. 웹 배포·반복 재생을 허용하는 라이선스의 파일을 새로 고르고 출처를 기록한다(§9). 그 전엔 버튼만 두고 소리 자리를 비워 둔다

### 3-5. 끝 화면

```
┌─────────────────────────────┐
│     ( 꾸벅 조는 모티 )         │
│                              │
│   잠깐 같이 앉아 있었네요       │
│                              │
│ 이번 주말, 이런 카페 하나       │
│ 어때요?                       │
│                              │
│ [ 쉴 곳 지도에서 카페 보기 ]    │
│                              │
│ 한 번 더 앉아 있기 · 친구에게   │
│                              │
│ 모먼트튠이 만든 곳             │  ← 작게
└─────────────────────────────┘
```

- 문구 **«잠깐 같이 앉아 있었네요»** 확정(창업자) — 한 일만 말하고 효과는 말하지 않는다(«마음이 편해졌죠?» ✗)
- **[쉴 곳 지도에서 카페 보기]** = App Store 캠페인 링크(그대로 쓴다):
  `https://apps.apple.com/kr/app/apple-store/id6802705637?pt=129286034&ct=artbox_cafe&mt=8`
  - `/kr/` 이 꼭 있어야 웹 브라우저에서 열린다(한국 스토어 전용 앱)
  - **`momenttune://` 는 웹 방문자에게 쓰지 않는다** — 앱이 없으면 Safari 오류가 난다. 앱에서 열었을 때(`?from=momenttune`)만 «모먼트튠으로 돌아가기»
- **친구에게** = 기기 공유 시트(`navigator.share`)로 작품 주소 하나 — 우리 문구를 덧붙이지 않는다. 공유 시트가 없으면 주소 복사
- **한 번 더 앉아 있기** = 처음부터

### 3-6. 접근성

- **움직임 줄이기**(`prefers-reduced-motion`): 비·빗방울 정지 · 모티는 가끔 깜빡임만 · 끝 화면은 바로 · 빗소리는 켠 경우 그대로
- 키보드: 스페이스로 «두드리기»(차례로 유리 → 머그 → 모티 → 창밖) · 끝 화면이 뜨면 포커스를 옮긴다
- 화면 읽기: 장면을 한 문장으로(«비 오는 날 카페 창가에서 모티가 코코아를 마시고 있어요») · 두드림 반응도 짧게
- 한국어 메타 제목·설명 · OG 이미지(장면 한 장) — 링크 미리보기가 곧 첫인상이다

7. 창업자 개인 스레드 글 · 15초 화면 녹화(`?from=threads` · `?from=insta`) — **발신은 창업자**

## 6. 재는 것 — 숫자 기준 없이 «재기만»

- 방문: `?from=` 별 서버 요청 수(사람 수가 아니라 방문 수)
- 끝까지: 끝 화면 자원 요청 수(서버 로그 합계)
- 넘어감: App Store Connect 캠페인 `ct=artbox_cafe` 의 페이지 조회·다운로드 — 서로 다른 Apple 계정 5개 이상 · 24시간 뒤에야 보인다
- 웹 재방문은 쿠키 없이 잴 수 없다 — 대신 앱으로 넘어온 사람의 «쉴 곳에 다녀왔다» 확인을 본다(MomentTune 쪽)
- 감상: 창업자 주변 몇 명에게 링크를 보내 «또 열어 볼 것 같나» 를 직접 묻는다
